# cellbycell1-media

Videos and code for the faceless Instagram account [@cellbycell1](https://www.instagram.com/cellbycell1/)
(daily Excel & Google Sheets tips). Instagram pulls each Reel from its raw.githubusercontent.com URL.

- `STYLE.md`: style guide, rules and the daily publishing workflow
- `content/calendar.csv`: upcoming topics · `content/posted.csv`: what has been posted
- `lib/engine.py`: drawing + render engine · `lib/music_upbeat.py`: original music generated in code
- `reels/<date>-<slug>/`: one folder per Reel (`render.py`, mp4, `cover.jpg`, `caption.txt`)
